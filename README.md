# Wanderers & Ridges 🏔️

> High mountain passes, subterranean rivers, and canyon trails across India.

A personal expedition journal and travel platform by **Subhasish Pradhan**, documenting high-altitude Himalayan road trips and subterranean karst river expeditions across India.

---

## 🧭 Flagship Expeditions

1. **Arunachal Pradesh Winter Expedition (2023)** (`/trips/arunachal-pradesh-2023`)
   - High-altitude winter road trip across western Arunachal Pradesh.
   - Highlights: Sela Pass (13,700 FT), Nuranang Falls, Tawang Buddha, Bum La Pass (15,200 FT McMahon Line), Sangetsar Lake, and Dirang Valley paragliding.
2. **Meghalaya Canyons & Caves Odyssey (2026)** (`/trips/meghalaya-canyons-2026`)
   - Motorcycle, waterfall, and karst cave expedition across West & East Jaintia and East Khasi Hills.
   - Highlights: Cobalt basin of Phe Phe Falls, subterranean bamboo rafting in Krem Chympe, Wah Umngot suspension bridge at Shnongpdeng, 50-million-year-old marine gastropod fossils at Mawsmai Cave, and Mawkdok Dympep Gorge.
3. **Trips Archive** (`/trips`)
   - Interactive category filtering: *Himalayan High Passes*, *Canyons & Caves*, *Motorcycle Trails*.
4. **Field Manifesto & Gear** (`/about`)
   - Technical field kit, optical setups, water/karst safety gear, and road ethics.

## 🎨 Design System & Visuals

- **Palette:** Nature-immersive tones (Deep Pine `#0B1311`, Alpine Stone `#13221E`, Glacial River Teal `#38A3A5`, Dawn Ochre `#DDA15E`, Botanical Green `#2D6A4F`).
- **Typography:** Editorial Serif headings (`Playfair Display`, `Fraunces`, `Cinzel`) paired with modern sans (`Plus Jakarta Sans`).
- **Atmospheric UI:** Translucent frosted glassmorphism (`backdrop-blur-md`), topographic contour grid motif, elevation pill badges, and ambient radial glow accents.
- **Interactive Lightbox:** Fullscreen high-resolution photo viewer with captions, keyboard controls (`Esc`), and smooth zoom-on-hover effects.

---

## 🛠️ Tech Stack

- **Framework:** [Astro](https://astro.build/) (Static Site Generation)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) with `@tailwindcss/typography`
- **TypeScript:** Strict type validation (`astro check` clean)
- **Zero Runtime Bloat:** Native CSS-driven transitions and client-side interactions with 0 heavy external runtime dependencies.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ (tested on Node v20/v24)
- npm

### Installation
```bash
# Clone the repository
git clone https://github.com/pradhansubhasish16-sudo/wanderers-and-ridges.git
cd wanderers-and-ridges

# Install dependencies
npm install --legacy-peer-deps
```

### Development
```bash
# Start Astro development server
npm run dev
```

### Production Build & Preview
```bash
# Build static site to dist/
npm run build

# Preview static production build
npm run preview
# or run custom server:
node server.js
```
